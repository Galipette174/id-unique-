Five ui - Galipette
Support = discord.gg/fiveui 

Commande du script : 

/uid → Affiche ton UID unique

/uid <id> → UID d’un joueur connecté

/uid <uid> → Retrouve le joueur s’il est en ligne

/uidreload → Recharge le cache UID

/uidinfo <uid> → Infos UID (offline OK)

/whois <id|uid> → Infos complètes joueur

/checkban <uid> → Vérifie un ban

/banuid <uid> [raison] → Ban permanent

/permbanuid <uid> [raison] → Alias ban permanent

/tempbanuid <uid> <minutes> [raison] → Ban temporaire

/unbanuid <uid> → Unban
